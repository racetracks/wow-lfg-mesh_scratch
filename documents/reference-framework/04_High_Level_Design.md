## Where each type is defined
| Type | Defined in (the capability's folder) |
| --- | --- |
| `CMP` | its folder's `Readme.md` heading |
| `APX` | `00_Appendix.md` |
| `HLD`, `DDS`, `ARC` | `04_High_Level_Design.md`, `05_Detailed_Design.md`, `06_Architecture.md` headings |
| `IMP`, `STP` | `07_Roadmap.md` |
| `DEC` | where it is decided (`00_Decisions.md`, or the design document that holds the fork) |
| `SAV` | `05_Detailed_Design.md` of the addon folder |
| `TST`, `CHK` | `15_Tests.md` ([`DEC-00014`](https://github.com/racetracks/wow-lfg-mesh_scratch/blob/main/documents/reference-framework/12_User_Guides/12_02_Documentation_Rules.md#dec-00014)) |
| `ISS` | the registry row (GitHub URL as its file) and `11_Known_Issues.md` |
| `BLD` | `16_Registries/` build ledger |
| `RET` | the registry's Retirements table and the folder's `00_References.md` |
